# LineOfBots Modding Kit — дополнение v24.6

**Файл ядра:** `lineofgui2` (ветка `main`) · **Дата:** 8 ноября 2026
**Это дополнение к MODDING_FOR_AI.md** — описывает новый API v24.5–v24.6 и исправленные баги лоадера.
Мод проверяет совместимость: `if api.version and api.version >= "v24.6" then ... end`

---

## 1. Новый официальный API

### Промпт ИИ — БЕЗ хуков
```lua
-- Подсказка в блок MOD ACTIONS системного промпта (убирается при выгрузке сама):
api.hint("Если игрок просит передать предмет — используй [DO:give ник предмет]")

api.removeHint("текст")  -- снять свою подсказку досрочно

-- Легальное расширение способностей (снимает «You CANNOT …» для перечисленного):
api.ability("teleport", "можешь телепортироваться к игроку по [DO:tp ник]")
api.removeAbility("teleport")
```
**Правило:** хукать `makeSystemPrompt` ради добавления текста больше НЕ НУЖНО.
`api.hint` + `api.ability` закрывают 95% сценариев, ради которых моды хукали промпт.

### Чат от лица бота
```lua
api.say("не нашёл игрока Влад, попробуй точный ник")  -- pcall + журнал внутри
```

### Версия кита
```lua
api.version  -- строка "v24.6" (дублируется в api.loader.VERSION)
```

## 2. Безопасность: что теперь гарантирует лоадер

| Механизм | До v24.5 | Теперь |
|---|---|---|
| `api.hook(fn, repl)` | repl ставился как есть; ошибка мода = «бот замолчал» | repl вызывается через обёртку: конвенция `repl(оригинал, ...)` работает, при ошибке — журнал с именем мода, уведомление, **авто-снятие хука**, вызов уходит в оригинал |
| `api.patch(name, wrapper)` | ошибка wrapper падала на каждом вызове | fail-safe: журнал + прозрачный вызов оригинала |
| `api.override(name, fn)` | ошибка замены падала на каждом вызове | fail-safe: журнал + вызов оригинала |
| `api.connect(signal, fn)` | битый signal ронял загрузку мода целиком | Connect под pcall; ошибка обработчика — в журнал с именем мода |
| Событие падения конвейера | только print в консоль F9 | notify в GUI + запись в журнал модов с перечнем модов с хуками |
| Загрузка модов | одна ошибка внутри `loadAll` молча убивала поток — моды не грузились до перезахода | `loadAll` под pcall: журнал + уведомление |

**Конвенция хуков:** `api.hook(LOB_CORE.makeSystemPrompt, function(old, settings) return old(settings) .. "\nМоё правило" end)` — как в §6.8 документации. Прежде эта конвенция НЕ соответствовала реализации; с v24.5 она официальная (старая сырая `repl(...)` тоже принимается для совместимости).

**После первой же ошибки хук снимается САМ** — мод должен это переживать: проверяй результат, при повторном усилении промпта используй `api.hint`.

## 3. Исправленные баги лоадера (v24.6)

1. **Моды молча не грузились** — на инжекторах без `loadstring` (только `load`) падали `loadMetaCache/loadLib/loadOne/api.data`; теперь единая точка `LOB_MODS.loadChunk` (loadstring → load → понятная ошибка в журнал).
2. **Табы-призраки** — выгрузка мода с 2+ своими вкладками оставляла каждую вторую вкладку в сайдбаре навсегда (мутация списка во время `ipairs`); обход переписан на обратный.
3. **Родные [DO:теги] умирали** — если мод переопределял `wave`/`follow` и т.п., после выгрузки тег оставался сломан до перезахода; теперь родной обработчик сохраняется и возвращается.
4. **Утечка подписок** — `api.on` не чистился при выгрузке; каждый цикл вкл/выкл наращивал `LOB_MODS.events`; теперь подписки мода снимаются, `fire` идёт по снимку списка.
5. **Запрос вкладки до готовности GUI терялся** — теперь таб регистрируется и создаётся при ближайшей пересборке интерфейса.
6. **api.every/api.delay** с не-функцией не спамят журнал; **api.version** не дублируется.

## 4. Чеклист приёма мода (обновление)

1. Включил мод → бот ответил на два сообщения (ловит класс «немого бота»).
2. Выключил мод → в сайдбаре не осталось вкладок мода, родные теги работают.
3. Включил мод снова → подписки/хуки не задублировались (журнал чистый).
4. Мод с ошибкой в `patch/hook/connect` → в GUI всплывает уведомление с именем мода, бот продолжает работать.

## 5. Ловушка кириллицы (напоминание из отчёта моддера)

`string.lower/upper` в Luau НЕ меняют регистр кириллицы. Для ников и текста игрока:
приводите регистр через `utf8.codepoint` или транслит (Влад → Vlad), иначе сравнение молча не сработает.
